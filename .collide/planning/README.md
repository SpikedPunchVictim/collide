# Collide planning

This folder is Collide's shared planning root. It holds the build tasks (`epics/`) and the spike records
(`spikes/`) that Collide's own `collide/plan` markdown provider reads, in the layout of `IMPLEMENTATION_PLAN.md` 0.10.
The `collide task` CLI is not built yet (Stage 2), so items are edited by hand.

For how items, ids, links, statuses, spike records and the plan fit together, read
[`docs/tasks-and-docs.md`](../../docs/tasks-and-docs.md).
