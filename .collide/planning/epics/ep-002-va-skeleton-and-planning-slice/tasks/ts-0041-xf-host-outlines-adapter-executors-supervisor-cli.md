- `cargo build` and `cargo clippy` pass.

- Decisions for the owner: (1) The stub-exit design: a handler is a function whose body is a tagged `todo!`, and `execute_stub` catches that one panic with `catch_unwind` and prints `collide <cmd>: not built yet (<tag>, Stage <n>)` with a new exit code, `6` (`exit::NOT_BUILT`, added beside 0 to 5; `HELP`'s exit code line is untouched and `collide --help` states the 6 in the tree).
